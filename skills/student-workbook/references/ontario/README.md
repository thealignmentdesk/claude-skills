# Ontario curriculum: official expectations, offline copy

Exported 13 Oct 2026 from the Ministry of Education's Curriculum and Resources site (https://www.dcp.edu.gov.on.ca/en/) with `scripts/ontario_curriculum.py`. Each file lists the strands, overall expectations and specific expectations with their codes and the Ministry's exact wording.

Use these when you can't reach the website (the Claude app's sandbox often can't). Read only the file for the grade and subject you need. When you can reach the site, the live page wins if they differ.

Grades 7-8 take History and Geography instead of Social Studies, and grades 10-12 have course-based curricula (e.g. MPM2D, MCR3U, MHF4U): look those up online, or ask the user for the course code and describe the skill in plain words.
