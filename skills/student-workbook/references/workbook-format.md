# Workbook format

## Size and mix by grade

| Grades | Print | Question formats | Notes |
|---|---|---|---|
| 1-3 | Big (the script switches automatically) | Fill in the blank, circle the answer (multiple choice with 2-3 choices), count, number lines, one-step word problems | Short sentences. One idea per question. Lots of space to write. |
| 4-6 | Normal | Multiple choice (4 choices), short answer, two-step word problems, "show your work", one "explain your thinking" | Mix calculation and reasoning. |
| 7-8 | Normal | As 4-6, plus multi-step problems and short written explanations | Include one real-life problem per section. |
| 9-12 | Normal | Multi-step problems, proofs/justifications where the course has them, data and graph questions, short essays for humanities | Match the course code (Ontario: e.g. MTH1W, MCR3U). |

## Each section
- **Heading**: the topic in plain words ("Adding fractions with the same denominator").
- **Curriculum line**: the expectation code and wording (from the official source).
- **Remember**: 2-4 bullet points the child can read.
- **Example**: one solved example, 2-5 steps.
- **Questions**: Warm-up (easiest, about 30%), Practice (about 50%), Challenge (about 20%, one step beyond, still in the grade).

## Numbers and context
- Use the region's money, units and spelling (Canada: dollars and cents, metric, "colour"; US: dollars, US customary where the standard uses it, "color").
- Names in word problems: varied, made-up first names. No brands, no real people.
- Distractors in multiple choice come from real mistakes (adding denominators, place-value slips), not random numbers.

## Answer key
- Every question has an answer. Where it helps, one line of explanation ("3/8 + 2/8 = 5/8: add the tops, keep the bottom").
- For open questions, give what a good answer includes, not one fixed sentence.

## Before you finish, check
- Every answer re-solved from scratch, and matches.
- Each multiple-choice question has exactly one correct choice.
- Nothing above the grade.
- No real names or personal details from a scanned page.
