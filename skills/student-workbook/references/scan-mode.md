# Scan mode: a workbook from the child's test or homework

## 1. Privacy first
Before you read the page, if the name area isn't covered, say once: "Tip: cover your child's name and school before sharing. I won't repeat any names I see." Then carry on. Never write a child's, teacher's or school's name in the chat or the workbook.

## 2. Read the page
For each question, note:
- **Topic and skill**: e.g. "adding fractions with like denominators".
- **Format**: multiple choice, fill in the blank, word problem, show your work, matching, true/false, short written answer.
- **Difficulty**: numbers involved, steps needed, whether a picture or diagram was used.
- **Curriculum expectation**: the one it practises (from the official source for the region and grade).
- **Marked?** If you can see ticks, crosses, a score or corrections: right or wrong.
- **The mistake**, when it's wrong and the work is visible: name the likely misconception in one line ("added the denominators", "forgot to regroup", "read 'how many more' as 'how many altogether'"). Don't guess when the work isn't shown; just say it was wrong.

If the photo is hard to read, say which questions you couldn't read and ask for a clearer photo of that part. Don't invent questions you can't see.

If the grade or region isn't clear from the page, ask (Step 1 of SKILL.md).

## 3. Confirm the plan
Show the user a short summary, e.g.:

> I can see 8 questions on fractions (Grade 4). Wrong: 3 and 6. Both added the bottom numbers.
> Plan: 20 new questions on the same patterns, half of them on adding fractions, plus a short "Remember" box about why the bottom number stays the same. OK?

## 4. Write new questions on the same patterns
- Same skill, same format, similar difficulty. New numbers, names and contexts.
- **Never copy a question** from the page, and don't solve the original test in the chat. If asked, explain one similar example step by step instead.
- Weighting: about half of the questions on the patterns the child got wrong, then the rest on the others. If nothing was wrong, make it a little harder (more Challenge questions).
- Start each wrong-answer pattern with an easier warm-up, so the child gets an early win.
- Put a short note at the top of the answer key (`from_scan.notes`) saying which test questions each section targets, so the adult knows why.
